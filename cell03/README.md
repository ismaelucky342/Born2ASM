# cell03 - Advanced Exercises

Advanced assembly exercises in modern assembler `.s` syntax. These exercises increase in difficulty and target algorithmic thinking, data manipulation, and low-level optimization.

Each exercise file includes an enunciado and a complete solution in `.s`.

Exercises:
- ex00: String processing
- ex01: Array traversal and indexing
- ex02: Bitwise operations
- ex03: Stack manipulation
- ex04: Macro usage and code reuse
- ex05: Optimization practices
- ex06: Table-based algorithms
- ex07: Branch prediction and performance
