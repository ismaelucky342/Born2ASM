# cell02 - Assembly Basics

Basic assembly practice for learning core concepts. This cell contains a set of foundational exercises with increasing complexity, using modern `.s` syntax.

Each exercise file includes an enunciado and a complete solution in `.s`.

Exercises:
- ex00: Basic program structure and segments
- ex01: Registers and data movement
- ex02: Arithmetic operations
- ex03: Memory access and addressing
- ex04: Branching and conditions
- ex05: Loop construction
- ex06: Subroutines and function calls
- ex07: Simple data structures
