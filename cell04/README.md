# cell04 - Intermediate Projects

Intermediate modern assembler projects in `.s`. These projects introduce more complete programs and integration of several concepts, preparing you for larger systems.

Each project file includes an enunciado and a complete solution in `.s`.

Projects:
- ex00: Calculator program
- ex01: Simple parser
- ex02: Basic math library
- ex03: Memory manager
- ex04: File-style I/O emulator
- ex05: Small virtual device driver
